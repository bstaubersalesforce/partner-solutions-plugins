# Stage 9 — Assemble

Bind every stage into the one plan document. This is orchestrator work (not a subagent) — it
requires the whole picture.

## Assemble into the template
Fill `../../templates/account-tech-plan.md`:
1. **Theory of Growth** at the very top — a short narrative of where the partnership is going
   and its potential. This is the executive hook; write it last, from the whole plan.
2. **Posture callout** (read-first) — the elevation-not-encroachment framing + exec-sponsor
   pairing, surfaced prominently near the top (`../trust-posture.md`).
3. **V2MOM frame** per `../v2mom-frame.md` — Vision, Values (incl. elevation-not-encroachment),
   Methods (the workstreams, **one block each — add as many as the plan has**, each with
   **nested Measures**), Obstacles (every one traced to a gap-closure row), and the
   cross-cutting Measures line.
4. The section bodies from Stages 1–8, in the template's order.
5. **Owners + next steps** — a named SF driver per workstream/thread (doubles as proof the
   partnership is resourced) and the immediate next actions.
6. **Reusable lessons applied** — the prior strategic-ISV patterns this plan borrows
   (`../trust-posture.md`), and a closing **Sources** banner (notes/site/Slack/Org62 scan date)
   with the **INTERNAL ONLY — scrub** line.

## Confidence + provenance
Tag inferred/unconfirmed items (`[proposed]`, `[confirm]`); list named assumptions and open
items. Record which sections degraded (unavailable subagent) so a later run completes them.

## Deliver
- Default output: the internal plan document.
- On request: post as an **internal** Slack canvas (fresh section IDs from a read before any
  update; nested bullets allowed; ATX headings only).
- Partner-facing version: only on request, **after** the data-safety scrub
  (`../org62-case-scan.md`).

## Living
Set the re-review date (default: next QBR). On re-run, refresh — do not regenerate — per
`../best-practice-frames.md` and the gap-closure KPI in `stage-07-roadmap-gaps.md`.
