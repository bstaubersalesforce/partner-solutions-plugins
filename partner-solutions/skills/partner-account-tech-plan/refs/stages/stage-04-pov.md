# Stage 4 — Tech Strategy POV (+ commercial, red team, readiness)

The strategic core. Dispatch `tech-strat-pov-forge` and its downstream stages as subagents,
feeding them the Stage-0 context and the trust posture.

## POV (core)
Run `tech-strat-pov-forge` for problem / vision / solution / **workstreams** / architecture.
Map the workstreams (which become V2MOM **Methods**) to the partner's own strategic frame when
one exists. Carry the elevation posture (`../trust-posture.md`) into the positioning.

## Downstream stages (pull these in — they are first-class plan sections)
- **Commercial / Consumption Opportunities** — `tech-strat-pov-forge` **Stage 18**: Agentforce
  credits, Data Cloud, Shield/Backup, pull-through SKUs, and any new-commercial-opportunity
  assessment. This is a required section, not an afterthought.
- **Red Team Assessment** — `tech-strat-pov-forge` **Stage 9**: competitive threats, churn,
  platform-dependency, 18-month roadmap-overlap invalidation, commercial-model pressure test.
- **Partner Readiness Scorecard** — `tech-strat-pov-forge` **Stage 12**: the 18-attribute RAG +
  1–3 rank.

## Optional downstream (offer, don't force)
Marketecture (St.14), MVP build plan (St.8), competitive assessment (St.19), POV/investor
decks (St.17/10), solution infographic (St.11) — generate on request.

## Hand-off
Workstreams → V2MOM Methods (with nested Measures per `../v2mom-frame.md`). Red-team findings
and readiness-scorecard reds → Obstacles + gap-closure rows (Stage 7). Consumption → the
cross-cutting consumption-growth Measure.
