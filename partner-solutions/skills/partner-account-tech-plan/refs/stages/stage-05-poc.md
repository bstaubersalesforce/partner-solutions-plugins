# Stage 5 — PoC opportunities (optional)

Where a workstream needs proof, identify installable PoC candidates. Optional — include only
when a Method benefits from a working artifact.

## How
Dispatch `pie-poc-forge` as a subagent with the relevant workstream/MVP definition from the
POV (Stage 4). It produces an installable PoC SFDX package plan.

## Scope discipline
One PoC per high-value workstream at most — a plan is not a build backlog. Each PoC must tie
to a named Method and a Measure it would move. If no workstream yet warrants a build, say so
and skip — do not manufacture a PoC to fill the section.

## Hand-off
Each PoC lands in the roadmap (Stage 7) at the horizon where it proves its workstream.
