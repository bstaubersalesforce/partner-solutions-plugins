# Solution Infographic Pre-Delivery Validation Checklist

Run every check before delivering the Solution Infographic HTML.
If any check fails, repair before delivering.

## Structure
- [ ] All panels present: Problem, Solution, Outcomes, Market, Branding
- [ ] No unfilled `{{PLACEHOLDER}}` tokens remain (scan the output)
- [ ] "Built on Salesforce" badge + company name + date present in Branding

## Content integrity (confirmed metrics only)
- [ ] Outcomes panel uses ONLY confirmed/achieved metrics — never proposed KPI targets dressed up as results
- [ ] Problem panel statistics are confirmed figures with a real basis
- [ ] Market panel size/CAGR is sourced; target vertical and one regulatory driver are named
- [ ] Problem statement condensed to ≤15 words without losing the specific constraint

## Failure → Repair
**Proposed target shown as a result:** Remove it from Outcomes. If no confirmed outcome metric exists, state that rather than implying one.
**Unfilled token:** Fill from POV, or omit the element cleanly — do not ship a visible `{{TOKEN}}`.
